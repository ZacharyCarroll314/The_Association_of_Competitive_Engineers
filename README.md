# The_Association_of_Competitive_Engineers

Hosting-ready website for the Association of Competitive Engineers.

## Publish with GitHub Pages

1. Go to GitHub and create a new repository named:
   `The_Association_of_Competitive_Engineers`

2. Set the repository to **Public**.

3. Upload `index.html` from this folder to the root of the repository.

4. In the repository, open:
   **Settings → Pages**

5. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**

6. Click **Save**.

GitHub will publish the site at a URL similar to:

`https://YOUR-GITHUB-USERNAME.github.io/The_Association_of_Competitive_Engineers/`

## Custom domain later
You can also connect a custom domain later from:
**Settings → Pages → Custom domain**
